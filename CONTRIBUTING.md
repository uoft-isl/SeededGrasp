# Contributing

Thanks for your interest in this project.

## How to contribute

- Open an issue to discuss bugs, questions, or proposed changes before
  starting significant work.
- Submit changes as a pull request. Keep PRs focused on a single change
  where possible, and describe what you changed and why.
- Match the existing code style (this repo uses `black` and `isort`;
  run `black . && isort .` before submitting).

## Reporting issues

When reporting a bug, please include:
- What you ran (command/config) and what you expected to happen.
- What actually happened (error message, stack trace, or incorrect output).
- Your environment (Python version, OS, GPU/driver if relevant).
